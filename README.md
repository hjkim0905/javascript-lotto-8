# javascript-lotto-precourse

## 과제3 - <🎱 로또 🎱> 기능 구현 목록

### 입력 처리

- [ ] 사용자로부터 로또 구입 금액 입력받기 (`Console.readLineAsync()` 사용)
  - [ ] `"구입금액을 입력해 주세요."` 메시지 출력
- [ ] 사용자로부터 당첨 번호 입력받기 (`Console.readLineAsync()` 사용)
  - [ ] `"당첨 번호를 입력해 주세요."` 메시지 출력
  - [ ] 구분자(쉼표)를 기준으로 당첨 번호 분리
  - [ ] 제공된 Lotto 클래스 사용
- [ ] 사용자로부터 보너스 번호 입력받기 (`Console.readLineAsync()` 사용)
  - [ ] `"보너스 번호를 입력해 주세요."` 메시지 출력

### 결과 계산

- [ ] 입력 받은 로또 구입 금액/1000 계산하여 로또 수량 도출
  - [x] 각 발행한 로또에 중복되지 않은 6개의 정수(1부터 45 사이) 부여 (`MissionUtils.Random.pickUniqueNumbersInRange(1, 45, 6)` 사용)
  - [x] 제공된 Lotto 클래스 사용
  - [ ] 로또 번호 오름차순 정렬
- [ ] 입력 받은 당첨 번호와 발행된 로또의 6개 정수를 비교
  - [ ] 6개 모두 일치하지 않고 5개만 일치했을 경우 발행된 로또의 6개 정수와 보너스 번호를 비교
- [ ] 당첨 내역 계산
  - [ ] 1등부터 6등 각각의 개수
- [ ] 수익률 계산
  - [ ] `당첨 금액` / `구입 금액` \* `100%`
  - [ ] 소수점 둘째 자리에서 반올림

### 예외 처리

- [ ] Error 발생 시 `process.exit()`을 호출하지 않고 `[ERROR]` 메시지와 함께 Error throw
- [x] 구입 금액 입력
  - [x] 빈 문자열 입력 시
  - [x] 숫자가 아닌 값 입력 시
  - [x] 1000 미만 값 입력 시
  - [x] 1000으로 나눴을 때 정수형 숫자로 나눠떨어지지 않는 경우
- [x] 당첨 번호 입력
  - [x] 1부터 45 사이 외의 로또 번호 입력 시
  - [x] 정수가 아닌 값 입력 시
  - [x] 6개 숫자가 아닌 갯수 입력 시 (빈 문자열도 같이 검증 역할)
  - [x] 중복된 번호 포함 시
- [ ] 보너스 번호 입력
  - [ ] 1부터 45 사이 외의 로또 번호 입력 시
  - [ ] 빈 문자열 입력 시
  - [ ] 정수가 아닌 값 입력 시
  - [ ] 당첨 번호와 중복 시

### 출력

- [ ] 발행한 로또 수량 출력 (`Console.print()` 사용)
  - [ ] 출력 형식 맞추기 (`"~개를 구매했습니다."\n`)
- [ ] 발행한 각 로또의 번호 출력 (`Console.print()` 사용)
  - [ ] 출력 형식 맞추기 (`"[번호, 번호, 번호, 번호, 번호, 번호]"`)
- [ ] 당첨 내역 출력 (`Console.print()` 사용)
  - [ ] 출력 형식 맞추기 (`"당첨 통계\n---\n"`)
  - [ ] 출력 형식 맞추기 (`"3개 일치 (5,000원) - ~개\n4개 일치 (50,000원) - ~개\n5개 일치 (1,500,000원) - ~개\n5개 일치, 보너스 볼 일치 (30,000,000원) - ~개\n6개 일치 (2,000,000,000원) - ~개"`)
- [ ] 총 수익률 출력 (`Console.print()` 사용)
  - [ ] 출력 형식 맞추기 (`"총 수익률은 ~%입니다."`)
